# Orange Hostels Management & Resident Safety System

## Project Background
This system is developed as an end-of-year simulation and modeling project targeting student accommodation management. It is custom-built as a case study for **Orange Hostels**, serving students of **Kampala University Luweero Campus**, located in **Luweero District, Katikamu Town Council, Butanza Sub-county, Nakyewa Village**.

## Key Features
- **Rooms Inventory Management:** Browse available hostel blocks and room capacities.
- **Student Registration:** Secure onboarding with hashed credentials and registration numbers.
- **Room Booking & Allocation:** Real-time reservation status tracking (Pending/Confirmed).
- **Payment Verification:** Mobile Money and bank reference logging linked directly to bookings.
- **Emergency SOS Panic Desk:** Instant alert broadcast for medical, security, and fire hazards.
- **Manager Control Dashboard:** Real-time oversight of revenue metrics, active emergencies, and system bookings.

## Technology Stack
- **Frontend/UI:** Streamlit Python Web Framework
- **Backend/Database:** Python with SQLite (`orange_hostels.db`)
